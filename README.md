# 🌍 Tracet — Travel Journal & Map App

**Tracet** is a React Native mobile application built with Expo and Firebase that allows travelers to drop pins, save locations, document memories, and explore local surroundings interactively.

---

## Features

- **Interactive Hybrid Map:** Drop pins anywhere on the globe, view city boundaries, and search places via Google Places API.
- **Custom Location Pins:** Categorize and inspect saved travel spots with custom markers.
- **Profile & Account Management:** Manage personal information, phone numbers, and profile pictures with local filesystem caching.
- **Firebase Authentication:** Secure login, password management, and account deletion.

---

## Upcoming Features

- **🤖 AI Travel Assistant:** Interactive AI chat tab to generate custom travel itineraries, local recommendations, and trip summaries.
- **📖 Travel Journal:** Multimedia journal tab to log daily photos, notes, and travel entries tied to specific pins.
- **👥 Social & Connections:** Native support for adding friends, sharing saved pins, and direct messaging between travelers.
